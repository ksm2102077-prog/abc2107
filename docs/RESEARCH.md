# 盤面と当たり判定の調査メモ

アプリで使っている数値の根拠です。公式の数値は公開されていないので、実機のスクショを測って決めました。
長さはすべて「盤面の横幅（左の壁〜右の壁）＝ W」を基準にしています。

## 使った資料

| 資料 | 内容 |
| --- | --- |
| GitHub の公開リポジトリ `eonian5176/monst_autofarmer` | Android（1080×2340、縦横比19.5:9）の実機バトル画面スクショ 14 枚。iPhone 15 Pro Max（1290×2796）とほぼ同じ縦横比 |
| GitHub の公開リポジトリ `ChihaluPrg/MonsterStrike_AutoPlay` | Android（1080×1920、16:9）の実機バトル画面スクショ 1 枚 |
| モンスト獣神日和「モンストのステージの大きさの横縦比率は？」 | プロチーム今池壁ドンズの選手が2016年に出したクイズ「ステージの横縦比」の答えが 8:9 |
| 攻略Q&A・ブログ（GameWith、note「モンストPS上達への道」など） | 敵の判定は円、弱点は本体から出っ張った別の判定、ヒットバックで敵が少し下がる、など |

スクショそのものはゲームの著作物なので、このリポジトリには入れていません。

## 測った結果

### 盤面の位置（どの端末でも同じ関係）

- 盤面の絵は**画面の横幅いっぱい**。高さは **1.254 W**（1080×2340 でも 1080×1920 でも同じ）。
- 盤面の絵のすぐ下に黄色いパネル（HPゲージの枠）があり、その上端を基準にできる。
  - 1080×2340: パネル上端 = 1556 行目、盤面の絵の上端 ≈ 201 行目
  - 1080×1920: パネル上端 = 1434 行目、盤面の絵の上端 ≈ 80 行目

### 壁の位置

- **左右の壁 = 画面の左右端**。ダメージウォールのエフェクト（青い帯）が画面端を中心に左右対称に出ていた。右端の壁に接しているキャラの中心は端から 49〜50px。
- **上の壁 ≈ 330 行目、下の壁 ≈ 1545 行目**（1080×2340）。上下のダメージウォールの帯の中心と、上下の壁に接したキャラの位置から求めた。
  - 高さ 1215px ＝ **1.125 W**（縦横比 **8:9**）。2016年のクイズの答えと一致。
  - 下の壁はパネル上端より **0.0102 W** 上。上の壁はそこから 1.125 W 上（ボスのHPゲージの下あたり）。
  - つまり盤面の絵の上 0.119 W ぶん（ボスHPゲージが重なる帯）は、キャラが入れない場所。

### 自キャラの大きさ

- **当たり判定の半径 ≈ 0.0455 W**（1080px 幅で約 49px）。
  - 右の壁に接したキャラ: 中心が端から 49〜50px
  - 上の壁に接したキャラ: 中心が上の壁から 49〜51px
  - 下の壁に接したキャラ: 中心が下の壁から 50〜51px
- **見た目の円の半径 ≈ 0.082 W**（約 88〜90px）。判定は見た目の 6 割弱の大きさ。
- キャラ名ラベル（1st〜4th）の中心は、キャラの中心より 0.0565 W 上。ラベルの文字色はプレイヤー色（赤・金・緑・青）。
- バトル開始時の並びは横位置が W/5 ずつ（W/5, 2W/5, 3W/5, 4W/5）。

### ブロック

- 見た目で 0.12〜0.15 W 四方（立体の縁を含む）。アプリの初期値は 0.13 W。判定は四角形として扱う。

### 敵

- 判定は円（攻略界隈の多数説）。大きさは敵ごとに違うので、アプリではスクショに合わせて手で調整する。
- 弱点は本体から少し出っ張った別の円で、当たると変な方向に跳ねる（イレギュラーバウンドの原因）。必要なら小さい敵の円を重ねて表現できる。
- 当たった敵が少し下がる（ヒットバック）ので、真正面から当てると計算とずれることがある。

## 計算のしかた

- 自キャラを半径 r の円、壁を「中心が r だけ内側の線」として、中心の軌跡を計算する。
- 壁：入射角 = 反射角。角にちょうど当たったら来た方向へ戻る。
- 敵：中心どうしの距離が（敵の半径＋r）になったところで接触。接点の法線で鏡のように反射する。
- ブロック：自キャラが円なので、判定は「ブロックを r だけ太らせた角丸の四角」。面に当たれば面で、角に当たれば角を中心とした円で反射する。
- 貫通タイプ・すり抜け設定の敵は線を曲げず、当たった回数だけ数える。味方も線を曲げず、触れたかだけ判定する。
- 400 通りのランダムな盤面で、軌道が壁や物体を突き抜けないことを自動テストで確認している（`tests/physics.test.js`）。

## まだ分からないこと

- iPhone 15 Pro Max 実機のスクショでの位置関係は、同じ縦横比の Android 端末から推定している。パネルを自動で見つけてから位置を決めるので大きくはずれないはずだが、ずれていたらメニューの「盤面の位置合わせ」で直せる。
- 自キャラの判定の形（円か多角形か）は公式情報がない。壁に当たる時に六角形のエフェクトが出ることから「六角形」説もあるが、円として扱っている。
