# 遠距離狙撃

スマホのブラウザで遊べる、超リアル重視の長距離狙撃ゲームです。距離をミルで測り、DOPEカードを読み、風を読んで、ダイヤルを回して撃ちます。

- 公開URL（GitHub Pages を有効にした後）: `https://ksm2102077-prog.github.io/abc2107/sniper/`
- 横向き推奨。縦向きでも遊べます。音が出ます。
- 進行状況は端末の中（localStorage）にだけ保存されます。

## キャンペーン（8任務）

| # | 任務 | 舞台 | 距離の目安 | 主な課題 |
|---|---|---|---|---|
| 1 | 乾いた射場 | 砂漠・訓練 | 300〜750m | ミル測距、DOPE、風読みの練習 |
| 2 | 峠の監視哨 | 山岳 | 約640m | 撃ち下ろし（傾斜補正）、2人目までの速さ |
| 3 | 涸れ川の車列 | 砂漠 | 約820m | 標的の識別、歩く標的へのリード、強い陽炎 |
| 4 | 羊飼いの谷 | 山岳 | 約980m | 土塀越しの胸から上、時間制限、谷の回る風 |
| 5 | 稜線の中継所 | 高山 | 約1140m | 氷点下・高い密度高度、撃ち上げ |
| 6 | 砂丘の向こう | 砂漠 | 約1350m | 強い横風と突風 |
| 7 | 格納庫の発電機 | 岩石砂漠 | 約1600m | 12.7mm弾での対物射撃、スピンドリフト |
| 8 | 鷹の巣 | 高山 | 約2050m | 飛行時間3秒超、コリオリ、立ち止まる瞬間を待つ |

任務を成功させると、.300 Win Mag → .338 ラプア・マグナム → 12.7mm（.50 BMG）と銃が増えます。

## 物理モデル

- **弾道**: 質点モデル（3自由度）を中点法で1ms刻みに積分。空気抵抗は G7 標準抗力曲線と各弾の G7 弾道係数から計算。
- **大気**: 気温・現地気圧・湿度から空気密度と音速を計算。密度高度も表示。初速は気温で変わる。
- **風**: 射線を3区間に分け、区間ごとに強さと向きが違う。突風は風下へ流れていく。弾は空気に対する相対速度で抵抗を受ける。
- **スピンドリフト**: Miller の式で安定係数を出し、Litz の近似式で右への横ずれを計算。
- **コリオリ**: 任務ごとの緯度で地球の自転ベクトルを持ち、加速度 −2Ω×v を積分に入れている。
- **ばらつき**: 初速の標準偏差、銃の集弾性、冷えた銃身の初弾のずれ。
- **人の要素**: 呼吸の周期で上下に揺れる、息止めは数秒は安定するが長いと震える、心拍の脈動、ガク引き、反動、ボルト操作で構えがずれる。

### 弾薬データ

| 銃 | 弾 | 初速 | G7 BC |
|---|---|---|---|
| 7.62mm | 175gr（M118LR 相当） | 792 m/s（2600fps） | 0.243 |
| .300 Win Mag | 220gr（Mk248 Mod1 相当） | 869 m/s（2850fps） | 0.310 |
| .338 LM | 300gr | 820 m/s | 0.368 |
| .50 BMG | 750gr | 838 m/s（29インチ銃身として） | 0.524 |

同じ G7 BC 0.243・2650fps・100ヤードゼロの公開計算表（1000ヤードで約404インチ落下・残速約1146fps）と比べて、落下量は約2%、残速は約3%以内で一致します（`tests/ballistics.test.js`）。

## 警戒と発見

撃つと発射音が届いた敵から順に警戒し、遮蔽物へ逃げます。弾が近くを通った者・着弾の近くの者はすぐ反応します。同じ位置から撃つほど、また砂ぼこりが立つ位置・大口径ほど発見度が上がります。発見されると反撃が始まり、移動か離脱をしないと被弾して任務失敗になります。

## 開発者向け

ビルド不要の素の HTML/CSS/JavaScript と three.js（CDN）。

```
sniper/index.html        画面の骨組み
sniper/css/sniper.css    見た目
sniper/js/ballistics.js  外部弾道（G7、大気、スピンドリフト、コリオリ、DOPE表）
sniper/js/data.js        銃・弾薬・任務のデータ
sniper/js/world.js       地形・空・植生・建物・旗・風の場
sniper/js/actors.js      人物モデル・行動・被弾
sniper/js/fx.js          着弾・流血・弾の軌跡
sniper/js/audio.js       効果音（WebAudioで合成）
sniper/js/ui.js          画面・パネル・結果
sniper/js/game.js        描画・入力・射撃・当たり判定・警戒・観測手
```

```
npm run test:sniper            # 弾道計算の単体テスト
npm run build:sniper-artifact  # 1つの HTML にまとめた版を dist/sniper.html に出力
```
